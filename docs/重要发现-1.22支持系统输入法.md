# 🔴 重要发现：RetroArch 1.22+ 原生支持 Android 系统输入法

> 调查日期：2026-10-08
> 触发：用户装了我编的 1.22.2 中文版后发现「可以直接用手机的键盘打字」，
>       而他之前的 1.21.0 只能用 RetroArch 自绘的键盘。

## 结论

**RetroArch 1.22 起新增了 `input_android_system_keyboard` 设置，默认 `true`。**
打开时，菜单里的文本输入框会调用**手机的输入法**（Gboard / 讯飞 / 百度 / 搜狗），
**可以直接打中文 —— 不需要本项目的中文键盘页。**

```c
// config.def.h:1909
#define DEFAULT_INPUT_ANDROID_SYSTEM_KEYBOARD true

// configuration.h:741
bool input_android_system_keyboard;

// menu/menu_setting.c:15966   设置项：设置 → 输入 → Android 系统键盘
```

## 实现方式（Java + JNI）

`pkg/android/phoenix-common/src/.../RetroActivityCommon.java`

```java
private EditText keyboardEditText;          // 隐藏的 1×1 输入框（alpha=0）

public void showKeyboard(final String label, final String initialText) {
    // ... 建一个 1x1、alpha=0 的 EditText，addContentView 上去
    keyboardEditText.requestFocus();

    InputMethodManager imm = (InputMethodManager)
          getSystemService(Context.INPUT_METHOD_SERVICE);
    if (imm != null)
        imm.showSoftInput(keyboardEditText, InputMethodManager.SHOW_FORCED);
}

// 文本实时回传 native（边打边传）
keyboardEditText.addTextChangedListener(new TextWatcher() {
    public void afterTextChanged(Editable s) {
        onSystemKeyboardInput(s.toString(), false);
    }
});
// 回车/完成 → 收尾
public native void onSystemKeyboardInput(String text, boolean finished);
```

native 侧：

```c
// input/drivers/android_input.c:1192
/* The IME is only reachable if the Java side resolved showKeyboard. */
if (android_app && android_app->showKeyboard)
    ...  // 发布 INP_FLAG_NATIVE_KB_AVAIL

// input/input_driver.c:12704  /  7841
INP_FLAG_NATIVE_KB_AVAIL   // 系统键盘可用
INP_FLAG_NATIVE_KB_SHOWN   // 系统键盘弹着
```

**原版 1.21.0 的 APK 里没有这段 —— 所以只能退回自绘 OSK。**

## 影响

| 场景 | 该怎么办 |
|---|---|
| **RetroArch ≥ 1.22 + 系统输入法可用** | **直接用手机输入法打中文**，本项目的中文键盘页用不上 |
| RetroArch < 1.22 | 用本项目的中文键盘页（或升级） |
| 系统输入法被杀/不可用 | 用本项目的中文键盘页兜底 |
| 想要物理/手柄式操作 | 中文键盘页（不用切输入法）|

**两条路互不冲突**：系统键盘在时它优先，不在时自绘 OSK 顶上。

## 验证方法

```bash
# 看设置值（1.22 默认就是 true）
adb shell "grep system_keyboard /sdcard/Android/data/com.retroarch.aarch64.cn/files/retroarch.cfg"
# → input_android_system_keyboard = "true"

# 在 RetroArch 里：设置 → 输入 → Android 系统键盘（开关）
```

## 顺带发现：ANR 是首次启动才有

用户第一次装完打开看到「RetroArch 中文版没有响应」。查 logcat：

```
ANR in com.retroarch.aarch64.cn/com.retroarch.browser.mainmenu.MainMenuActivity
Reason: Waited 5002ms for MotionEvent(action=DOWN)
```

但实测：
- 窗口其实 313ms 就画出来了（`Displayed ... +313ms`）
- 第二次启动完全正常，菜单带图标渲染完整
- UDP 55355 网络遥控 `GET_STATUS` 正常返回 `GET_STATUS CONTENTLESS`

**判断：首次启动时初始化较重（9,489 项 assets 在 APK 里），MIUI 的 ANR 判定太急。
第二次起就正常了。** 不是代码问题。

## 另外：这个版本可以直接远程遥控

`network_cmd_enable = "true"` + 端口 55355（UDP），命令表在 `command.h` 的 `map[]`：

```
MENU_TOGGLE   开关菜单
MENU_UP / MENU_DOWN / MENU_LEFT / MENU_RIGHT   菜单导航
MENU_A        确认        MENU_B      返回
OSK           显示/隐藏软键盘
GET_STATUS    查询状态    HELP        列全部命令
SHOW_MSG <msg>            在屏幕上显示消息
LOAD_CONTENT <core>|<rom> 直接启动游戏
```

**这个在 MIUI 挡了 `adb shell input`（INJECT_EVENTS）的时候特别有用 —— 绕过触摸封锁。**
