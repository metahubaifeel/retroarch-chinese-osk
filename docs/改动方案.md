## 二、方案 A：拼音首字母索引页（推荐先做这个）

### 2.1 键盘页设计

```
┌─────────────────────────────────────────────────────┐
│ 第 0 页：声母索引（点一下跳到对应页）                   │
├─────────────────────────────────────────────────────┤
│ 1  2  3  4  5  6  7  8  9  0  ⇦                      │
│ a  b  c  d  e  f  g  h  i  j  ⏎                      │
│ k  l  m  n  o  p  q  r  s  t  ⇩                      │
│ u  v  w  x  y  z  '  _  .  ⊕                          │
└─────────────────────────────────────────────────────┘
        ↓ 点 a
┌─────────────────────────────────────────────────────┐
│ 第 a 页：以 a 开头的常用字（按使用频率排序）             │
│ 1  2  3  4  5  6  7  8  9  0  ⇦                      │
│ 啊 阿 埃 挨 哎 唉 哀 皑 癌 蔼  ⏎                      │
│ 矮 艾 碍 爱 隘 鞍 氨 安 俺 按  ⇩                      │
│ 暗 岸 胺 案 肮 昂 盎 凹 敖 熬  ⊕                      │
│  ← 这一页末位 「返回索引」                              │
└─────────────────────────────────────────────────────┘
```

**每页 44 格 = 40 个候选字 + 4 个功能键**

### 2.2 数据结构

```c
/* input/input_osk_utf8_pages.h */

/* 声母索引页（第 0 页）—— 复用 lowercase_grid + 一个标记 */
#define OSK_CHINESE_INDEX  "-1"   /* 特殊标记：跳到索引页 */

/* a 页 */
static const char *chinese_page_a[] = {
    "1","2","3","4","5","6","7","8","9","0","⇦",
    "啊","阿","埃","挨","哎","唉","哀","皑","癌","蔼","⏎",
    "矮","艾","碍","爱","隘","鞍","氨","安","俺","按","⇩",
    "暗","岸","胺","案","肮","昂","盎","凹","熬","奥","⌂"};

/* b 页 */
static const char *chinese_page_b[] = {
    "1","2","3","4","5","6","7","8","9","0","⇦",
    "八","巴","叭","扒","吧","芭","疤","拔","跋","靶","⏎",
    "把","坝","爸","罢","霸","白","柏","百","摆","佰","⇩",
    "败","拜","稗","斑","班","般","颁","板","版","扮","⌂"};

/* ... c 到 z 页 ... */

/* 中文页索引表 */
static const char **chinese_pages_zh[] = {
    chinese_page_a, chinese_page_b, /* ... */ chinese_page_z
};
```

**`⌂` = 返回声母索引页**

### 2.3 字表怎么生成（**脚本自动做，不用手工**）

```python
# 1. 抓取游戏名里出现的所有汉字
# 2. 用 pypinyin 拿到每个字的拼音首字母
# 3. 按「在游戏名里出现次数」降序排 → 最常用的排前面
# 4. 每 40 个切一页

from pypinyin import lazy_pinyin
import json, glob, os, collections

# 收集所有游戏名
chars = collections.Counter()
for f in glob.glob(os.path.expanduser(
        '~/手机备份/Redmi10X-playlists/加工版/*.lpl')):
    d = json.load(open(f, encoding='utf-8', errors='surrogateescape'))
    for it in d.get('items', []):
        for ch in it.get('label', ''):
            if '\u4e00' <= ch <= '\u9fff':
                chars[ch] += 1

print(f"共 {len(chars)} 个不同汉字，{sum(chars.values())} 次出现")

# 按拼音首字母分组
groups = collections.defaultdict(list)
for ch, cnt in chars.most_common():
    ini = lazy_pinyin(ch)[0][0].lower()
    if 'a' <= ini <= 'z':
        groups[ini].append((ch, cnt))

# 生成 C 数组
for ini in 'abcdefghijklmnopqrstuvwxyz':
    lst = groups[ini]
    print(f"/* {ini}: {len(lst)} 字，可用 {len(lst)//40 + 1} 页 */")
    for page in range(0, len(lst), 40):
        chunk = lst[page:page+40]
        name = f"chinese_page_{ini}_{page//40+1}"
        print(f"static const char *{name}[] = {{")
        print('    "1","2",...,"⇦",')
        # ... 拼 4 行 11 列
```

**这个脚本能在 1 分钟内生成全部 C 代码。**

### 2.4 切页逻辑（`input/input_driver.c`）

在 `input_event_osk_append()` 里加：

```c
/* 中文页：点声母索引 → 跳对应页 */
if (*osk_idx == OSK_CHINESE_INDEX && word && len <= 2)
{
   char c = word[0];
   if (c >= 'a' && c <= 'z')
   {
      prv_osk      = *osk_idx;
      *osk_idx     = (enum osk_type)(OSK_CHINESE_A + (c - 'a'));
      *osk_last_codepoint_len = 0;
      return;
   }
}

/* 中文页：点 ⌂ → 回索引 */
if (*osk_idx >= OSK_CHINESE_A && *osk_idx <= OSK_CHINESE_Z
      && word && strcmp(word, "⌂") == 0)
{
   *osk_idx = OSK_CHINESE_INDEX;
   return;
}

/* 中文页：点字 → 直接 append 这个 UTF-8 字符 */
if (*osk_idx >= OSK_CHINESE_A && *osk_idx <= OSK_CHINESE_Z)
{
   if (word && len > 0 && len <= 4)
   {
      /* 直接追加，不需要组字（中文一个字 = 一个完整字符）*/
      input_keyboard_line_append(keyboard_line, word, len);
      return;
   }
}
```

**注意：中文比韩文简单 —— 韩文要 3 个字母组合成 1 个音节，中文字符本身就是完整的，直接 append 就行。**

### 2.5 枚举（`input/input_osk.h`）

```c
#ifdef HAVE_LANGEXTRA
   OSK_HIRAGANA_PAGE1,
   OSK_HIRAGANA_PAGE2,
   OSK_KATAKANA_PAGE1,
   OSK_KATAKANA_PAGE2,
   OSK_KOREAN_PAGE1,
   OSK_CHINESE_INDEX,        /* ★ 新增：声母索引页 */
   OSK_CHINESE_A,            /* ★ 新增：a 页 */
   /* ... OSK_CHINESE_B ... OSK_CHINESE_Z */
   OSK_CHINESE_Z,            /* = OSK_CHINESE_A + 25 */
#endif
   OSK_TYPE_LAST
```

**⚠️ 注意：`enum` 中间不能有空洞，`OSK_TYPE_LAST` 要跟着挪。**

### 2.6 网格选择（`input/input_driver.c` 里的 `input_event_osk_append`）

原代码是 `memcpy(osk_grid, korean_page1_grid, sizeof(...))`，改成 switch：

```c
switch (*osk_idx)
{
   case OSK_LOWERCASE_LATIN:
      memcpy(osk_grid, lowercase_grid, sizeof(lowercase_grid));
      break;
   case OSK_UPPERCASE_LATIN:
      memcpy(osk_grid, uppercase_grid, sizeof(uppercase_grid));
      break;
   /* ... */
   case OSK_CHINESE_INDEX:
      memcpy(osk_grid, chinese_index_grid, sizeof(chinese_index_grid));
      break;
   default:
      if (*osk_idx >= OSK_CHINESE_A && *osk_idx <= OSK_CHINESE_Z)
      {
         int p = *osk_idx - OSK_CHINESE_A;
         memcpy(osk_grid, chinese_pages_zh[p], sizeof(osk_grid));
      }
      break;
}
```

## 三、方案 C：接 Android 系统输入法（终极方案）

### 3.1 思路

```
用户在 RetroArch 菜单点搜索框
        ↓
【C 侧】通过 JNI 调用 Java 方法          ← 新增
        ↓
【Java 侧】InputMethodManager.showSoftInput()  ← 新增
        ↓
系统输入法（Gboard）弹出，用户打「绿宝石」
        ↓
【Java 侧】commitText() 回调 → 通过 JNI 传回 C  ← 新增
        ↓
【C 侧】input_keyboard_line_append()      ← 已有
        ↓
搜索框显示「绿宝石」✅
```

### 3.2 要改的文件

```
pkg/android/phoenix/src/com/retroarch/browser/retroactivity/RetroActivityFuture.java
   + InputMethodManager 相关代码

pkg/android/phoenix/src/com/retroarch/browser/retroactivity/RetroActivityCommon.java
   + 软键盘显隐

pkg/android/phoenix/jni/retroarch-activity.c    （或类似）
   + JNI 方法：retroarch_show_ime() / retroarch_hide_ime()
   + JNI 回调：nativeSetImeText(const char* utf8)

input/input_driver.c
   + input_osk_native_available() 返回 true
   + 接 nativeSetImeText 的文本
```

**工作量大：Java + JNI + C 三头改，还要处理软键盘遮挡、返回键、生命周期。**

**但这是唯一能"真正打中文"的方案。**

## 四、构建步骤（Android）

```bash
# ── 环境 ──
sudo apt install -y git build-essential openjdk-17-jdk
# Android SDK（命令行工具）
# Android NDK r23b 或更新

# ── 源码 ──
cd ~/build
git clone --depth 1 https://github.com/libretro/RetroArch.git
cd RetroArch

# ── 配置（确保开 langextra）──
./configure --enable-langextra

# ── 编译 ──
cd pkg/android/phoenix
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME=/path/to/android-ndk

# 只编 arm64（Redmi 10X 是天玑820 = arm64-v8a）
./gradlew assembleNormalUniversalRelease

# ── 产物 ──
ls -la build/outputs/apk/normalUniversal/release/
#   RetroArch-release.apk

# ── 签名（测试可用 debug key）──
keytool -genkey -v -keystore my.keystore -alias ra -keyalg RSA \
        -keysize 2048 -validity 10000 -storepass 123456 -keypass 123456 \
        -dname "CN=test"
apksigner sign --ks my.keystore --ks-pass pass:123456 RetroArch-release.apk

# ── 安装 ──
adb install -r RetroArch-release.apk
```

**⚠️ 卸载原版会丢配置。建议：**
```bash
# 先备份配置和数据
adb pull /sdcard/Android/data/com.retroarch.aarch64/files/ ./ra-config-backup/
# 改装新版后用同一个包名，配置目录不变（如果是升级安装）
```

**⚠️ 更好的做法：改包名，装成两个 App 并存**
```
pkg/android/phoenix/build.gradle:
    applicationId "com.retroarch.aarch64.cn"     ← 改成自己的
```
这样原版和你改的版本可以同时存在，互不影响。

## 六、风险

| 风险 | 说明 | 应对 |
|---|---|---|
| **API 变更** | `input_event_osk_append` 签名在版本间变过 | 对着**你那个版本**的 tag 改，别用 master |
| **枚举错位** | `OSK_TYPE_LAST` 是数组大小的依据 | 加完枚举后检查所有 `OSK_TYPE_LAST` 用法 |
| **网格越界** | `memcpy(osk_grid, ...)` 大小要匹配 | 每个页严格 44 个元素 |
| **字表太长** | 26 页 × N 页，二进制膨胀 | 只收录游戏名里真实出现的字（脚本自动过滤）|
| **升级丢失** | 官方更新后要重新合并 | 保持改动最小，写清 patch |

---

## 七、建议的实施顺序

```
第 1 步：把 Android 编译环境跑通，编一个【没改动的】RetroArch
        → 确认能装能跑（这步最容易卡）

第 2 步：只加一个【假中文页】（就 44 个汉字），验证：
        → 键盘能显示中文
        → 点字能进搜索框

第 3 步：用脚本生成完整字表，替换进源码

第 4 步：如果第 3 步体验不好（翻页慢），再考虑方案 C（系统输入法）

第 5 步：打包成 patch 文件，方便以后升级重新应用
```

**第 1 步是最大的拦路虎。先把它啃下来。**
